# BYC Camp Management

NodeJS Web Application

## Registration

- Camper Registration form
- Payment
- Discounts based on number of children attending
  - The third child registered in one family is cheaper, as is the fourth, etc
- Legal signature for medical release forms
- Camper info goes into a database
- Campers should receive a QR code in their email after registration that they can use at check in

## Camp Management

- Campers should be assigned to dorms according to gender and age group
- Workers and dorm leaders should be assigned to dorms
  - Workers have their own separate dorms
- Drag and drop to assign people to dorms manually if changes are needed after the default auto-assignment
- Dorms should have parameters such as number of beds, whether it is a boys or girls dorm, etc.
- Camp admins can scan camper QR codes at registration to check them in and have them automatically assigned to a dorm
  - The admin should be able to see right away where the camper is assigned, so they can tell the camper where to go
- Camp admins should be able to search camper names in case camper doesn't have a QR code and click a button to check them in
- Dorm leaders and workers should be able to be checked in similarly
- Camp admins should be able to have a printable dorm report showing what campers are checked in for specific dorms, so those reports can be given to dorm leaders for roll call so the dorm leaders know who should be there and who hasn't arrived to camp yet.
- Camp admins should be able to upload a CSV or spreadsheet of campers who are registered along with info about the campers to the backend. The software may not be done before the camp registration opens this year, but should be done by the time the camp begins, so the registration may not be used until next year, but the admin/management side will still be needed to be used without the registration system.
