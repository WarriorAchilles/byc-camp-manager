This project is a webapp for managing a church youth camp, called Believer's Youth Camp, or BYC for short. It has two parts, an admin management/camper check-in piece, and a registration piece. The two parts share the same database.

Useful files/folders:
- the development plan and specs for the pieces and for the project as a whole lives in the /docs folder.
- docs/specs.md is the master spec sheet for the project. 
- docs/development-plan contains steps for building each piece of the project

Don't run cdk commands or dev commands that run the server or client locally. Instruct the user what commands to run when these are needed.
